# Lid-Driven Cavity Simulation (OpenFOAM)

## Overview

This case demonstrates the classic **lid-driven cavity flow**, a standard benchmark problem in Computational Fluid Dynamics (CFD).

A square cavity is filled with fluid. The top wall moves at a constant velocity, driving the flow, while the other walls remain stationary. This induces a circulating vortex inside the cavity.

This case serves as:
- A **first validation simulation**
- A **learning example for OpenFOAM**
- A **foundation for reduced-order modeling (slosh project)**

## Physical Problem

- Fluid: incompressible, Newtonian
- Domain: square cavity
- Flow: transient, laminar

### Boundary Conditions

| Boundary      | Condition              |
|--------------|------------------------|
| Top wall     | Moving (drives flow)   |
| Bottom wall  | No-slip (U = 0)        |
| Side walls   | No-slip (U = 0)        |

---

## Solver

We use:

```
icoFoam
```

### What is icoFoam?

- Transient incompressible Navier–Stokes solver
- Uses the **PISO algorithm**
- Suitable for laminar flows

---

## Case Structure

```
SIM_Cavity/
├── 0/           # Initial & boundary conditions
├── constant/    # Physical properties & mesh
├── system/      # Solver configuration
```

---

### 0/ (Initial Conditions)

Contains:
- `U` → velocity field
- `p` → pressure field

Defines the starting state of the simulation.

---

### constant/

Contains:

#### transportProperties
Defines viscosity (`nu`).

#### polyMesh/
Generated by `blockMesh`. Defines geometry and mesh.

---

### system/

Contains:

#### controlDict
- Selects solver (`icoFoam`)
- Defines time stepping
- Controls output

#### fvSchemes
Defines discretization methods.

#### fvSolution
Defines solver settings.

Key section:

```
PISO
{
    nCorrectors 2;
    nNonOrthogonalCorrectors 0;
    pRefCell 0;
    pRefValue 0;
}
```

---

## Important Concepts

### Pressure Reference

In incompressible flow:
- Only pressure differences matter
- We must fix one reference value

This is done using:
- `pRefCell`
- `pRefValue`

---

### PISO Algorithm

Handles pressure–velocity coupling.

Think of it as:
- Predict velocity
- Correct pressure
- Iterate within each timestep

## How to Run

### Step 1 — Load OpenFOAM

From repo root:

```
source ../../scripts/load_openfoam.sh
```

---

### Step 2 — Navigate to case

```
cd sims/SIM_Cavity
```

---

### Step 3 — Generate mesh

```
blockMesh
```

---

### Step 4 — Check mesh

```
checkMesh
```

Expect:
```
Mesh OK.
```

---

### Step 5 — Run simulation

```
icoFoam
```

You should see:

```
Time = 0.005
Time = 0.01
...
```
